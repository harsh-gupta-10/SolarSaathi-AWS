# Agent Execution Rules

## Before coding
Read all relevant documentation.

## For every feature
1. Identify data model.
2. Identify API contract.
3. Identify deterministic business rules.
4. Identify UI states.
5. Add tests.
6. Implement.
7. Validate.

## For policy features
1. Source registry first.
2. Ingestion adapter.
3. Normalization.
4. Versioning.
5. Validation.
6. Approval.
7. Policy engine.
8. UI provenance.

## For AI features
Define:
- input context
- retrieved sources
- allowed output
- forbidden claims
- fallback
- logging

## Never
- fabricate a government scheme
- hardcode a changing subsidy into UI
- add a state subsidy because a blog says it exists
- combine benefits without compatibility
- call AI-generated imagery an engineering design
- leak private data
- add a new cloud platform
