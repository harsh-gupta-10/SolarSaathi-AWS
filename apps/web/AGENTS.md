# Web Agent Rules

- Read root `AGENTS.md` and relevant docs first.
- UI must reflect actual API state.
- Do not calculate subsidy totals in React components.
- Do not hardcode government benefit amounts.
- Show policy provenance and stale/conflict states.
- Keep the roof confirmation flow explicit.
- Keep AI-generated concepts clearly labelled as concepts.

- Use accessible, responsive UI.
